## 🚀 Project Experiences

### 💡 Featured & Freelance Projects

#### 🌐 [EveryTranslate](https://github.com/miracorhan/EveryTranslate) (2024 - 2026)
*A high-performance localization platform orchestrating multiple translation engines with failover mechanisms.*
- **Orchestration**: Intelligent translation engine failover and priority switching.
- **Localization**: Full UI localization in 15 languages (including RTL layout support).
- **Billing**: Multi-gateway billing integration (Stripe, PayPal, Apple Pay, Google Pay).
- *Tech stack: ASP.NET Core 9, EF Core, SignalR, Redis, Stripe.net, xUnit, RTL.*

#### 🛡️ [BikesGuard](https://github.com/miracorhan/BikesGuard) (2026)
*A secure e-commerce & bike tracking system designed with Clean Architecture.*
- **Key Features**: Bike registry, stolen reports, automated invoicing, order processing, and payment integrations.
- *Tech stack: .NET 9, Clean Architecture, SQL Server, JWT, Identity, Mapster, QuestPDF, xUnit, Moq.*

#### 🎨 Nexcustom Product Customization (2024 - 2026)
*An e-commerce product customizer system integrated with the Etsy API.*
- **Custom Editor**: Store owners prepare template visual assets and clients customize them in-browser using a custom HTML5 canvas editor.
- *Tech stack: ASP.NET Core 9, EF Core, Hangfire, Automapper, Fabric.js, IMAP Mail.*

#### 🤖 Birobot Management System (2024 - 2025)
*Management and payment system for robotics education centers.*
- **Key Features**: Institution setup, student tracking, invoicing/payments, attendance, and reporting.
- *Tech stack: .NET 8 C#, EF Core, Angular, Clean Architecture, CQRS, MediatR, Hangfire.*

### 🏢 Selected Enterprise & Municipal Systems (Yirmibes Software, 2020 - 2024)

#### 🏭 Yirmibes Web ERP Software
*Modular enterprise resource planning (ERP) system for trade and manufacturing.*
- **Modules**: Shipped modules for purchasing, sales, finance, exports, inventory management, production control, and B2B platforms.
- *Tech stack: .NET 4.8 MVC, MSSQL Multi-database, API Gateway (Ocelot), Quartz.NET, WebSockets, DevExpress, FastReport.*

#### 🔗 E-Commerce Netsis ERP Integration
*Real-time synchronization service for major marketplaces and accounting.*
- **Sync**: Integrated inventory, orders, journals, and e-invoices/e-waybills from Trendyol, Hepsiburada, N11, and Gittigidiyor into Netsis ERP.
- *Tech stack: .NET 7 MVC, MSSQL Multi-database, EF Core, Hangfire, REST/SOAP APIs.*

#### ⚖️ KVKK Management (GDPR Compliance System) (2023)
*Consent management system complying with GDPR rules for multi-company architectures.*
- **Features**: Permission tracking, e-mail/SMS verifications, and integration with IYS and TUBITAK timestamp services.
- *Tech stack: .NET 8 MVC C#, MSSQL, SMTP, SMS, JWT/Cookie Hybrid Auth.*

#### 🗺️ Municipality Address Management System (2023)
*Official addressing and GIS mapping platform for Aydin Municipality.*
- **E-Government**: Integrated with Ministry of Interior General Directorate of Population and Citizenship Affairs (NVI) for e-devlet sync.
- *Tech stack: .NET 8 MVC C#, PostgreSQL, WebAPI, REST.*

#### 🐟 E-Pool Aqua (2023)
*Multi-tenant aquaculture cloud tracking and reporting system.*
- **Usage**: Used by 10+ fish farms to track daily production status, feed, and logistics.
- *Tech stack: .NET 7 MVC, MSSQL, Quartz.*

#### 🎟️ Feedback Center (2022)
*Centralized ticketing and customer support dashboard.*
- **Traffic**: Scaled to process 1,000+ support requests per month with real-time notifications.
- *Tech stack: .NET 7 MVC, Web API, SignalR, CookieAuth.*
